The Rust runtime copyright document covers multiple targets. For example, its MPL-2.0 fortanix-sgx-abi entry is SGX-specific and is not part of the shipped Linux GNU target. This snapshot is not an approval for additional build targets.

Tree-sitter embeds ICU Unicode headers; regex-syntax embeds Unicode data; unsafe-libyaml contains a translation of libyaml. Their original notices are preserved in addition to the crate-level declarations.

No third-party source is modified by this project. The Kotlin samples are original test inputs; Spring, JPA and servlet imports do not bundle those libraries.

The Linux binary dynamically uses system libraries such as glibc and libgcc_s. Those libraries, the JDK, the full Gradle distribution, Rust compiler and CI tools are not shipped in the binary archive. Repackaging them (for example in a container) requires a separate inventory and review.
